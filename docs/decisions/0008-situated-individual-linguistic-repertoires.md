# ADR 0008: Situated individual linguistic repertoires

- Status: Accepted
- Date: 2026-08-18

## Context

Communication mismatch can occur across region, class, family, peer group,
profession, institution, coalition, and platform. Treating any group as one
linguistic destiny would reproduce the simplification the simulation critiques.

## Decision

Give each fictional actor an individual repertoire of learned registers with
represented acquisition contexts. Select or switch registers according to
audience, relationship, channel, power, and pressure while preserving knowledge,
goals, interior orientation, and semantic commitments. Model world assumptions
separately from code.

## Consequences

- A register switch is not evidence of deceit or instability.
- Shared code is not evidence of shared belief, motive, relationship, or
  coordination.
- Different code can carry shared material agreement.
- Generation rejects incoherent actors rather than explaining them with a
  visible stability score.
- Full repertoire and switch history remain conclusion-gated.

## Alternatives considered

- Demographic speech templates were rejected as essentializing and inaccurate.
- One fixed voice per actor was rejected because situated code-switching is part
  of the represented system.
- Shared vocabulary as a graph edge was rejected because linguistic similarity
  does not establish an outward relationship.
