# Glossary

This glossary gives short navigational definitions. Canonical rules remain in
the linked specifications.

| Term | Meaning |
|---|---|
| Active code | The linguistic register currently selected for a protagonist. |
| Afterimage | A completed room's current metrics after later house events, distinct from its immutable close snapshot. |
| Ambient event | A scheduled, once-only modeled exposure that does not invent a player choice. |
| Assembled support | Source, evidence, institution, relationship, or distribution capacity made available by valid prior events. |
| Bridge | The second room beat, showing how an interpretation travels through a relationship, institution, or familiar form. |
| Choice access | The structural, enactment, timing, and last-resort eligibility result for one action. |
| Code collision | A systemic route in which communication-code friction widens interpretive gap without proving substantive disagreement or shared content. |
| Code convergence | Different coalition vocabularies expressing a shared concrete proposition or action. |
| Completion snapshot | Metrics frozen when a room's fourth decision resolves. |
| Correction | The fourth room beat, where repair, persistence, or bounded refusal becomes consequential. |
| Crossover | The third room beat, exposing reply access, communication friction, carrier compatibility, or wider consequence. |
| Direct crossing | Content or recognizable form moving through a represented shared channel or artifact format. |
| Discernment | Modeled capacity to identify the better-supported action. Fatigue does not lower it. |
| Distributed repair | A repair whose conditions can be assembled through several actors or rooms without one indispensable person. |
| Effect receipt | One target-specific record of metric, reach, support, layer, and crossing effects. |
| Enactment | Modeled current capacity to carry an action despite attention, verification, emotional, relational, and efficacy cost. |
| Efficacy fatigue | Load produced by the sense that careful correction cannot catch a moving cascade. |
| Entered room | A room whose seat the player has opened; entry changes disclosure but not clock time. |
| Fit | How readily an artifact's form feels native to the receiving social context; not a truth measure. |
| Generated pack | One validated seed, six scenarios, shared night, routes, pulses, and coherence report. |
| Generator version | Compatibility identifier for the scenario model produced by a seed. |
| House effect | A current outward connection created by an accepted event, not necessarily a direct content crossing. |
| Immutable truth | Authored incident record that player action and propagation cannot change. |
| Interpretation gap | Distance between represented record and audience reading; not a measure of intelligence or worth. |
| Last resort | One hidden-until-eligible, extraordinary nonviolent action for a high-discernment prosocial seat under extreme modeled load, with split consequences. |
| Logical clock | Shared modeled time advanced by accepted action duration or explicit movement to an arrival, never by player reading time. |
| Night state | Seed, elapsed minutes, turn, six room runtimes, decisions, ambient events, and processed pulses. |
| Non-amplification floor | A choice guaranteed at every beat that allows the player not to repeat, personalize, or amplify a claim regardless of enactment depletion. |
| Portable text | Player-controlled UTF-8 save envelope that is validated and previewed before restore. |
| Pressure contour | Internal, situational model of response availability; phases may be skipped, interrupted, revisited, omitted, or absent. |
| Register | One learned linguistic resource in an individual's modeled repertoire. |
| Relational move | Typed record of how a choice affects attribution, reply access, translation, protection, or repair. |
| Room reading | Represented audience interpretation, kept separate from the event record. |
| Save schema | Versioned structure of the portable envelope, separate from generator version. |
| Scene due | The room's current artifact has arrived on the logical clock. |
| Surface | The first room beat, introducing an artifact and immediate public reading. |
| Systemic route | A bounded shared-condition effect between rooms that does not by itself assert common content. |
| Trace | How much source, time, boundary, and context remain attached to an artifact. |
| Truth ledger | Immutable observed record and unresolved boundary for one incident. |
| Vague cue | Reviewed cross-room description permitted before both endpoints are entered. |
| World model | An actor's assumption about what an exchange is for, distinct from linguistic register, identity, ideology, and truth. |
