The direct instruction has highest precedence for this correction. The exact
attachment supplies the improved narrative and ten adversarial attacks; its
digest, not its display name or a later paraphrase, identifies the governing
bytes. Accepted CHORUS truth, causality, accessibility, privacy, determinism,
and provenance constraints remain binding. Existing implementation and tests
are evidence of earlier behavior, not authority to preserve an immersion break.

This register uses **Summary surface** to mean the complete `NightDebrief`
experience, not only the paragraphs returned by `buildNaturalizedSummary`.
The scope includes text that is visually hidden but exposed to assistive
technology, and conditional or generated text that appears only on some
completed paths. Maintainer documentation, source identifiers, type names,
test descriptions, and other internal code are outside the lexical prohibition.
The global application wordmark and pre-debrief rooms are also outside this
change unless their copy is rendered inside `NightDebrief`.

## Status vocabulary

| Status | Meaning |
|---|---|
| `Pending` | The requirement is authoritative but is not yet implemented and verified on a new source binding. |
| `Implemented` | Source changes exist, but the complete adversarial and accessibility evidence does not. |
| `Implemented; focused automated pass` | Source changes and the named focused automated gates pass on one binding, but the final full gate or applicable manual review remains open. |
| `Verified` | Positive, negative, boundary, mutation, and applicable combination tests pass on one identified implementation binding. |
| `Blocked` | A named authority, dependency, or unresolved conflict prevents implementation or verification. |
| `Superseded` | A later stable requirement replaces the row; the row and its evidence remain preserved. |

## Verification boundary

Passing these source and generated-copy contracts will demonstrate that the
implemented Summary stays in-world and preserves the listed causal and
epistemic distinctions on the identified source binding. It will not prove
universal reader understanding. Live browser inspection, VoiceOver or NVDA
reading order, 200% text zoom, forced colors, and manual editorial review remain
separate promotion evidence and must remain open until actually performed. The
repository-wide automated command passed on implementation digest
`65a23bf8126bac896b0217cf0623b029b26e4b9931f10b2927327237933adc84`;
that automated pass is not a substitute for live browser or assistive-technology
inspection.
